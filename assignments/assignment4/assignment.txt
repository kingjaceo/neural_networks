This assignment focuses on implementing and analyzing convolutional autoencoder models for image embedding and clustering, as well as generating synthetic images using generative models.

Task 1 (50 points):
Develop and evaluate a Deep Convolutional Autoencoder (DCAE) to reconstruct input images from a 512-dimensional latent representation using CIFAR-10 datasets. After training, use the encoder to map all images into this 512-dimensional feature space. Next, apply Principal Component Analysis (PCA) to reduce the embeddings to 10 dimensions, followed by K-means clustering to assign labels. Finally, use t-distributed stochastic neighbor embedding (t-SNE) on the 10-dimensional PCA features to project the data into 2D space, and visualize the results by comparing the generated cluster labels with the original labels.
